SECTION 2

AI-Supported Feedback

Focus question: Question 3 — Solve 2x + 4 = 14. The correct solution is x = 5.

Student A — Strong answer

Student response: “2x + 4 = 14. Subtract 4 from both sides: 2x = 10. Divide both sides by 2: x = 5.”

Reviewed feedback: Excellent work. Each inverse operation is applied to both sides, and the final answer is correct. You can verify it by substituting 5: 2(5) + 4 = 14. Keep showing each step clearly.

Teacher review: No mathematical correction was needed. A substitution check was added to strengthen the feedback.

Student B — Partly correct answer

Student response: “2x + 4 = 14, so 2x = 14 − 4 = 10. Therefore x = 10.”

Reviewed feedback: You correctly subtracted 4 from both sides and reached 2x = 10. One final step is missing: divide both sides by 2. The solution is x = 5. Try checking your answer in the original equation.

Teacher review: The feedback identifies the exact missing step and gives a next action without treating the whole response as incorrect.

Student C — Incorrect operation

Student response: “2x + 4 = 14. I add 4 to both sides, so 2x = 18. Then x = 9.”

Reviewed feedback: You remembered to use the same operation on both sides, but the operation should undo the +4. Subtract 4 from both sides: 2x = 10. Then divide by 2, giving x = 5. Remember: use inverse operations to isolate the variable.

Teacher review: The key misconception is identified: adding 4 does not undo the +4. The corrected feedback models the appropriate inverse operation.

Student D — Answer only

Student response: “x = 5.”

Reviewed feedback: Your final answer is correct. To demonstrate your reasoning, include the steps: subtract 4 from both sides to get 2x = 10, then divide by 2 to get x = 5. Can you also verify the result by substitution?

Teacher review: The answer alone does not show whether the student understands the method. Feedback therefore asks for working and a check rather than assuming how the answer was obtained.

AI PROCESS

Prompts Given to AI

Prompt 1 — Quiz creation

Act as a mathematics teacher. Create an 8-question multiple-choice quiz for lower-secondary students on solving one-variable linear equations. Include a range from basic one-step equations to equations with brackets and variables on both sides. Each question must have four options and exactly one correct answer. Check every answer mathematically and provide a separate answer key. Use clear, age-appropriate wording.

Prompt 2 — Feedback generation

Act as a supportive mathematics teacher. The question is: Solve 2x + 4 = 14. The correct answer is x = 5. Give specific, constructive feedback for each sample response. Identify what the student did correctly, explain any error accurately, and suggest one next step. Use an encouraging tone and do not praise incorrect mathematics as correct.

The sample responses and feedback above are presented as an AI-assisted draft that has been checked and edited by the teacher.

REFLECTION

Reflection

AI helped me create a set of questions at different levels and produce feedback quickly for students with different types of answers. It was especially useful for suggesting encouraging language and identifying a possible next step for each learner. However, AI-generated feedback still needs careful checking. For example, feedback must distinguish between a correct final answer and correct mathematical reasoning. A student may give the right answer without showing the method, or make an error when choosing an inverse operation. I reviewed the explanations, checked the calculations, and improved the feedback so that it addressed each student's actual mistake. Next time, I would test the quiz with students, collect real responses, and use their results to make the questions and feedback more closely match their learning needs.
